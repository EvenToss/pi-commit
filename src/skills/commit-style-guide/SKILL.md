# Git 提交规范

提交标题使用以下英文类型前缀之一：

- `feat`：新增功能
- `fix`：修复问题
- `refactor`：重构代码
- `docs`：文档变更
- `style`：仅格式调整
- `test`：测试相关
- `chore`：构建或工具链变更

格式：

```text
类型(scope): 中文标题
```

要求：

1. 类型前缀必须使用上面列出的值。
2. `scope` 可选，用于说明影响范围。
3. 冒号后的标题主体必须使用中文，简洁说明实际改动，标题不超过 50 个字符为宜。
4. 标题使用动词开头，例如“增加”“修复”“调整”“删除”。
5. 改动较大时，在正文中用中文说明修改原因和实现方式。
6. 不要夸大改动效果。

示例：

```text
feat(auth): 增加登录限流
```
